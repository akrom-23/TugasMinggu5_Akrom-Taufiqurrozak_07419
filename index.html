Tentang Saya

Belajar, mencoba, dan berkembang.

Saya adalah mahasiswa aktif Program Studi S1 Sistem Informasi di Fakultas Ilmu Komputer, Universitas Dian Nuswantoro. Saya memiliki ketertarikan dalam bidang pengembangan aplikasi web, perancangan basis data, dan analisis sistem informasi.

Saya senang mempelajari teknologi baru dan mengembangkan kemampuan melalui berbagai tugas serta proyek perkuliahan. Saya ingin memahami cara merancang sistem yang sesuai dengan kebutuhan pengguna.

Website ini merupakan pengembangan halaman profil dari Tugas 1 dengan menerapkan Bootstrap dan CSS eksternal agar tampilannya lebih rapi dan responsif.
